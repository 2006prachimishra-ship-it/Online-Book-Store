# Online Book Store 📚

## About the Project

This is a simple Online Book Store website that I created as part of my Web Development coursework at GL Bajaj Institute of Technology and Management.

The idea behind this project is to create a website where users can browse different books, explore categories, and navigate through basic bookstore pages. I have used HTML and CSS to build the website and organize its different sections.

## What does the website include?

The website has the following pages:

- **Home:** The main page of the bookstore.
- **Login:** A page for existing users to log in.
- **Registration:** A page for new users to register.
- **Catalogue:** Displays the available book categories.
- **Cart:** A shopping cart page.
- **Book Categories:** Separate pages for Civil, CSE, ECE and EEE books.

## Technologies Used

- HTML
- CSS

## Project Files

Here is a quick look at how the project is organized:

- `index.html` – Main entry page
- `home.html` – Home page
- `login.html` – Login page
- `registration.html` – Registration page
- `catalogue.html` – Book catalogue
- `cart.html` – Shopping cart
- `civil.html` – Civil Engineering books
- `cse.html` – Computer Science books
- `ece.html` – Electronics and Communication books
- `eee.html` – Electrical and Electronics books

## How to Run the Project

You can try out the website on your computer by following these steps:

1. Download or clone this repository.
2. Open the folder in VS Code.
3. Find the `index.html` file.
4. Open it in your browser to view the website.
